# Contributing to AuraPlan AI

Thank you for your interest in contributing to **AuraPlan AI — Autonomous Celebration & Event Architect**!

## Development Workflow

1. **Fork & Clone:**
   ```bash
   git clone https://github.com/snehalghadge59-blip/promptwars-event-planner.git
   cd promptwars-event-planner
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Run Local Development Server:**
   ```bash
   npm run dev
   ```

4. **Run Unit & Integration Tests:**
   ```bash
   npm test
   ```

5. **Type Verification & Production Build:**
   ```bash
   npm run build
   ```

## Code Standards
- Strict TypeScript adhering to modern ES2020+ standards.
- Reusable React components with JSDoc annotations.
- Full unit test coverage for calculation logic and export generators.
- Accessible HTML semantics and WCAG 2.1 AA compliant color contrast.
